Playboi Carti Music Library Assignment

This was a coding assignment i've doen for Intro to Programming Last winter, It was a very fun and interactive project where i developed a music library using python code, inspiried by my impecable music taste, Playboi Carti.This project gave me the chance to practise the skills i've learned in Intro to Programming, while having something that i can call my own work. My project allowed people to save, create, and shuffle through songs that they can download and be able to pull up on screen. It doesn't play any audio like a typical soundtrack but for the purpose of the assignment i thought adding a twist to the topic of a library organizer app was something unique to me.
